# Руководство по настройке донатов для Open Source проекта

## Обзор сервисов для донатов

| Сервис | Особенности | Комиссия |
|--------|-------------|----------|
| **GitHub Sponsors** | Интеграция с GitHub, без комиссии от GitHub | 0% (только платёжные сборы) |
| **Ko-fi** | Простой, без комиссии для разовых донатов | 0% разовые, 5% подписки |
| **Open Collective** | Прозрачная бухгалтерия, подходит для команд | 10% + платёжные сборы |
| **Buy Me a Coffee** | Популярный, простой интерфейс | 5% |
| **Patreon** | Подписная модель, контент для патронов | 5-12% |
| **Liberapay** | Для open-source, рекуррентные платежи | ~0% |
| **Polar.sh** | Новый, специально для OSS, bounties | 5% |

---

## Выбранный сервис: Ko-fi

### Почему Ko-fi

- Мгновенные выплаты (деньги сразу на PayPal/Stripe)
- 0% комиссии на разовые донаты
- Простой и понятный интерфейс
- Можно подключить и PayPal, и Stripe одновременно
- Можно добавить цели (например, "на сервер", "на новую фичу")

### Модели монетизации в Ko-fi

| Тип | Комиссия Ko-fi | Описание |
|-----|----------------|----------|
| **Разовые донаты** | 0% | "Купи мне кофе" — любая сумма |
| **Membership** | 5% | Ежемесячная подписка с уровнями |
| **Shop** | 5% | Продажа цифровых товаров |
| **Commissions** | 5% | Заказы на работу |

### Процесс для донатера

1. Донатер заходит на страницу `ko-fi.com/username`
2. Выбирает сумму (по умолчанию "1 кофе" = $3-5, настраивается)
3. Оплачивает через PayPal или карту (Stripe)
4. Деньги сразу поступают на PayPal/Stripe владельца

## Платёжные системы

### Stripe

**Статус в Сербии:** Доступен с 2023 года

**Для регистрации нужно:**
- PIB (порески идентификациони број)
- Матични број
- Банковский счёт в динарах (RSD) или евро (EUR)
- Данные директора/власника

**Процесс подключения к Ko-fi:**
1. Ko-fi перенаправляет на Stripe Connect
2. Создаёте аккаунт Stripe (или входите в существующий)
3. Проходите верификацию (паспорт/ID, адрес, банковские реквизиты)
4. Stripe связывается с Ko-fi автоматически

**Комиссия:** ~2.9% + $0.30 за транзакцию

### PayPal

**Статус в Сербии:** Доступен, но с ограничениями

**Важное ограничение:** Вывод на банковский счёт в Сербии недоступен напрямую!

**Варианты обхода:**
1. Держать на PayPal и тратить онлайн
2. Использовать Payoneer как мост
3. **Лучше использовать Stripe** — прямой вывод на сербский счёт

**Комиссия:** ~2.9% + $0.30 за транзакцию

### Рекомендация для Сербии

```
Ko-fi → Stripe → Сербский банковский счёт (EUR или RSD)
```

**Почему Stripe, а не PayPal:**
1. Прямой вывод на банк в Сербии
2. Лучшая отчётность для бухгалтерии
3. Меньше проблем с конвертацией

## Бухгалтерия и налоги в Сербии

### Юридический статус донатов

Донаты через Ko-fi — это **платежи за услуги/благодарность**, а не благотворительность. Облагаются налогом как обычный доход.

### Налогообложение

| Форма бизнеса | Налог | Примечания |
|---------------|-------|------------|
| **Предузетник** (ИП) | 10% на доход или паушал | Паушал проще |
| **д.о.о.** (ООО) | 15% порез на добит | Плюс дивиденды 15% |

### Бухгалтерский учёт

```
Приход: Донације/Услуге путем интернета
Конто: 641 - Приходи од продаје услуга
Документ: Извод из Stripe/PayPal
ПДВ: Обычно не применяется (услуги физлицам из-за рубежа)
```

### Что предоставить књиговођа (бухгалтеру)

- Месячные выписки из Stripe
- Курс конвертации (если в EUR/USD)
- Комиссии как трошкови (расходы)

### Нужна ли фактура для донатеров?

**Нет!** PayPal Business и Stripe предоставляют:
- Историю всех транзакций
- Выписки для бухгалтерии
- Отчёты по периодам (месяц/год)
- Данные для налоговой декларации

### Пример расчёта

```
1. Донатер платит $10 через Ko-fi
2. Ko-fi передаёт в Stripe (комиссия Ko-fi: 0%)
3. Stripe забирает ~$0.60 комиссии
4. $9.40 поступает на бизнес-счёт
5. Stripe формирует запись о транзакции
6. Учёт: $9.40 как доход, $0.60 как расход
```

## Чек-лист настройки

### Шаг 1: Регистрация в Ko-fi
- [ ] Зарегистрироваться на [ko-fi.com](https://ko-fi.com)
- [ ] Настроить профиль (имя, аватар, описание проекта)
- [ ] Настроить сумму "кофе" (по умолчанию $3-5)

### Шаг 2: Подключение Stripe
- [ ] Создать Stripe аккаунт для бизнеса
- [ ] Пройти верификацию (PIB, матични број, паспорт)
- [ ] Подключить банковский счёт (EUR или RSD)
- [ ] Связать Stripe с Ko-fi

### Шаг 3: Подключение PayPal (опционально)
- [ ] Создать PayPal Business аккаунт
- [ ] Связать PayPal с Ko-fi
- [ ] Помнить об ограничениях вывода в Сербии

### Шаг 4: Интеграция в проект
- [ ] Создать `.github/FUNDING.yml`
- [ ] Добавить раздел в README.md
- [ ] Добавить `funding` в pubspec.yaml

### Шаг 5: Бухгалтерия
- [ ] Сообщить књиговођа о новом источнике дохода
- [ ] Настроить ежемесячное скачивание выписок из Stripe
- [ ] Определить конто для учёта (641)

## Интеграция в GitHub репозиторий

### Файл `.github/FUNDING.yml`

```yaml
ko_fi: your_username
# github: your_username  # когда одобрят GitHub Sponsors
```

### Раздел в README.md

```markdown
## Support

If you find this library useful, consider supporting its development:

[![Ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/your_username)
```

### Поле в pubspec.yaml

```yaml
funding:
  - https://ko-fi.com/your_username
```
